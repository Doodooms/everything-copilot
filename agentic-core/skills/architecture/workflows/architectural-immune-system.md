- Basic debugging, simple code review, isolated implementation, or ordinary feature work

## Step 1 - Ground the challenge.

1. DO consume the assigned `risk_level`; inspect the materialized proposal, approved intent, system identity, invariants, boundaries, governance, and scale assumptions.
2. If a critical context item is missing, report the gap to the proposal owner rather than inventing it or expanding into an unbounded audit.

## Step 2 - Trace long-horizon failure mechanisms.

1. Apply all six lenses to the proposal: failure modes, entropy accumulation, governance erosion, scale transitions, identity drift, and long-horizon systemic stress.
2. For each plausible concern, connect a current design choice to a degradation mechanism, trajectory, observable signal, and likely impact; separate evidence from hypothesis.
3. Focus on gradual loss of coherence, boundary integrity, determinism, or maintainability, not only immediate outages or a generic premortem list.

## Step 3 - Return a ranked challenge.

1. Rank only material, evidence-grounded risks; state the affected invariant/boundary, mechanism, confidence, horizon, and smallest decision or mitigation that could reduce the risk.
2. Return unresolved assumptions and residual uncertainty to the proposal owner; do not redesign, implement, or claim approval.
