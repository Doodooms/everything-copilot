# Architecture decision record format

Place ADRs in the repository's established location. If none exists, use `docs/adr/` and create it only for the first approved decision. Number entries sequentially using the local naming convention.

```md
# {Short decision title}

{Context, chosen option, and reason in a concise paragraph.}
```

Add status, alternatives, or consequences only when a later reader needs them to understand a material choice or its effects.
