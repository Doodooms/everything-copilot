# Original Specification

## Raw intent

Provide a focused method for resolving codebase terminology, maintaining domain context, and recording only meaningful architecture decisions.

## Normalized requirements

- Read and preserve existing project vocabulary and decision records.
- Validate language against concrete domain scenarios and repository evidence.
- Keep context glossaries free of implementation detail.
- Create concise ADRs only for costly-to-reverse, non-obvious, genuine tradeoffs.
- Preserve unresolved domain decisions rather than inventing answers.

## Constraints and resolved decisions

- The supplied Codex package was reviewed as source material; this skill is re-authored for the workspace's routing and ownership contracts.
- Context and ADR files are created lazily and follow existing repository conventions.
