# Original Specification

## Raw intent

Offer a safe, fast prototype method for checking a state model, logic flow, or UI direction before production implementation.

## Normalized requirements

- Define a single question and a disposable, bounded artifact.
- Distinguish behavior/logic exploration from visual/interaction comparison.
- Keep side effects, credentials, and persistent data out of the prototype by default.
- Run a minimal check that proves the prototype can answer its question.
- Transfer validated insight, not unreviewed prototype code, into production work.

## Constraints and resolved decisions

- The supplied Codex skill's prototype patterns were selectively re-authored; host-specific branch, commit, and user-interface instructions were excluded.
- Date: 2026-09-24.
