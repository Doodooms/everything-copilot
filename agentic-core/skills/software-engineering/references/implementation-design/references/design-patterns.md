# Design patterns

Patterns name recurring forces; they are not implementation goals.

- Use Strategy only when multiple behavior variants are real and selected independently.
- Use a Factory only when construction varies beyond a trivial constructor.
- Use Repository only when it establishes a meaningful persistence boundary.
- Use Visitor only when traversal and extensibility justify its indirection.
- Avoid layers, interfaces, and wrappers that add no current variation, invariant, or test seam.
