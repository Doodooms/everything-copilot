# Algorithmic complexity

Compare candidates against realistic input size, growth, and required behavior.

- Consider worst-case time and memory as well as expected cost and update frequency.
- Distinguish exact from approximate, batch from streaming, and offline from online requirements.
- Parallelism adds synchronization, ordering, and failure costs; use it only when the workload and runtime justify it.
- Asymptotic improvement is not sufficient evidence for a practical win. Benchmark representative inputs when performance is a stated or observed requirement.
